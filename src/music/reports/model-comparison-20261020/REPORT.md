# MuSe B1/B2 추천 비교 — 공유용 발췌

> 공유용 발췌 사본. 개별 곡·Spotify ID·원본 API 응답은 포함하지 않는다. ReccoBeats 좌표에 의존하는 A/C1/C2 수치는 공개 조건 확인 전 보류했다. 원본은 비공개 로컬 폴더에 그대로 보존했다.

전체 원본 실험은 A/B1/B2/C1/C2 5종을 동일 공통 27,948곡에서 비교했다. 이 공유본은 MuSe V/A의 두 고정 정규화 B1/B2 집계와 방법만 제공하며, 전체 5모델 결과 공개본이 아니다. 출처·이용 범위는 [SOURCES](../SOURCES.md), 파일별 정제는 [SHARING-REVIEW](../SHARING-REVIEW.md)에 기록했다.

## 조건

목표 25개는 V/A 각각 {-1,-0.5,0,0.5,1}의 완전 격자다. 중앙 1·사분면 4·축 4·경계 16개이며 실제 음악 관측이나 이용자 목표 분포로 생성한 것이 아니다. Top-20, V=A 가중치 1, 제외 없음, 초기 반경 0.05, 2배 확대다. 최대 반경은 0.4 및 √8 두 조건이다. 핵심 함수 기본값(Top-100·초기 0.1)과 다르다. [protocol.json](protocol.json).

모델/영역별 집계는 [result.json](result.json), 원본 실행의 검증 요약은 [verification.json](verification.json)이다. 이 JSON의 original_run_result/원본 실행 카운터는 과거 5모델 실행 기록이며 이번 사본 생성의 테스트 결과가 아니다. 공유본 해시는 상위 [manifest.json](../manifest.json)에 별도로 기록한다.

## 한계

거리는 각 좌표계의 기하학적 수치이며 감정 정확도나 청취 품질 순위가 아니다. 빈 결과의 거리 평균을 0으로 채우지 않았다. Top-20 중복률은 교집합/20이며 부족 목록에 영향을 받는다. 16/25가 경계인 격자는 실제 이용자 분포가 아니다. Energy와 Arousal의 동일성을 가정하지 않는다.

중앙/경계·밀집/희박 영역을 층화한 블라인드 청취 평가에서 감정 적합도·선호·익숙함·다양성을 별도로 확인해야 한다. 본 작업에서는 원본 실험·청취·테스트를 재실행하지 않았다.
